# 日安TOKYO・A2戶型 居家配置模擬

由建商 CAD 原圖（`A2戶型.dwg`，AutoCAD 2018，單位 cm）**精確轉換**的互動式居家配置模擬器。
所有尺寸與圖面一致（內建 33 項自動化驗證，含 2D 量測、3D 座標往返、旋轉後距離、物件與鄰近點距離），
量測結果可直接用於施工溝通。

## 線上使用

**👉 https://garlicchives.github.io/myhome-a2/**

開啟即用（無需安裝）。配置自動儲存在瀏覽器（重開機接續編輯）。功能：

- **2D／3D 檢視**：縮放、平移、3D 旋轉視角
- **量測**：懸浮即顯示四向距離（含與家具距離）；兩點量測自動吸附 CAD 圖面節點
- **家具家電**：自訂長寬高新增；拖曳磁吸貼齊、推入直接疊放（滾輪換層）、整疊連動、
  Shift 多選＋群組旋轉、Ctrl+C/V 複製、禁止懸空、天花板上限警示
- **儲存**：配置自動存於瀏覽器（重開機自動接續）；「💾 版本」可另存多方案還原；
  「匯出／匯入」JSON 檔可備份與跨裝置分享

## 檔案

| 檔案 | 說明 |
|------|------|
| `index.html`／`A2戶型居家模擬.html` | 主系統（單一自包含 HTML） |
| `A2戶型列印圖.html` | 手繪用列印圖（10cm 格線、A3 1:50／A4 1:75，列印選 100% 實際大小） |
| `A2戶型.dwg`／`A2戶型.dxf` | CAD 原始檔與轉換中繼檔（唯一尺寸真值來源） |
| `A2戶型-圖面解析.md` | 圖面解析筆記（空間構成、尺寸全表、審查結論） |
| `tools/` | 重建管線：DWG→DXF→SVG＋抓點資料→HTML，含最終驗證腳本 |

## 驗證

開啟 [`?selftest=1`](https://garlicchives.github.io/myhome-a2/?selftest=1) 可即時執行 33 項精準性斷言（全 PASS 顯示綠字），
含 2D/3D 真實指標事件拖曳模擬（磁吸/疊放/拖出遲滯不閃爍）。
